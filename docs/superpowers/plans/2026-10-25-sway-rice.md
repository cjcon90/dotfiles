# Sway Rice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the sway desktop into a SwayFX/Dracula rice (full-bar waybar, refined rofi, swaylock-effects, swaync, swayosd, swappy) that also runs on a Fedora 44 work laptop.

**Architecture:** All config lives in `~/.dotfiles` (GNU stow, symlinked into `~`), on the `rice` branch. Edits to already-stowed files are live immediately; new config directories need `stow -R -t ~ .` from `~/.dotfiles`. `arch-setup` gets a package/step update on its own `rice` branch.

**Tech Stack:** swayfx 0.6 (AUR), waybar 0.15 (GTK CSS), rofi 2.0 (rasi), swaylock-effects 1.7 (AUR), swaync 0.12, swayosd 0.3, swappy, grim, slurp, bash.

**Spec:** `docs/superpowers/specs/2026-10-25-sway-rice-design.md`

## Global Constraints

- Dracula palette only: `#282a36` bg, `#21222c` darker bg, `#44475a` current line, `#f8f8f2` fg, `#6272a4` comment, `#8be9fd` cyan, `#50fa7b` green, `#ffb86c` orange, `#ff79c6` pink, `#bd93f9` purple, `#ff5555` red, `#f1fa8c` yellow.
- Keybindings, gaps (`inner 10`, `outer 5`), workspaces, `apply-display-profile.sh`, `bequiet-light-mount.conf` and the clock module stay unchanged, except where a task says otherwise.
- Wallpaper stays `output * bg ~/.config/sway/dracula-kraken.png fill`.
- Never `git push`. Commit locally on `rice` only. Commit messages: short verb-phrase title, plain prose body, end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Anything needing `sudo`/`yay` is run by the user, not the agent.
- No comments in config unless the why is non-obvious (one short line).

## Review Focus

1. **Blur leaking past the bar.** Expect the wallpaper in waybar's transparent margins to be sharp, not frosted. Pinned in Task 3 Step 6 (screenshot check).
2. **Region screenshot cancelled with Escape.** Expect nothing to happen: no swappy window, no error notification. Pinned in Task 8 Step 1/4.
3. **Volume key held at 100%.** Expect the level to stop at 100%, never over-amplify (today's `-l 1.0`). Pinned in Task 7 Step 4.
4. **No media playing.** Expect the left of the bar to show just the workspaces, with no empty padded gap. Pinned in Task 3 Step 6.
5. **Lock with two monitors connected.** Expect a blurred screenshot and ring on both outputs, and unlock working from either. Pinned in Task 5 Step 4.
